# Triage Labels

Engineering skills 使用五個 canonical triage roles。本檔將 roles 對應到本 repo Linear team 使用的 label 字串。

| mattpocock/skills canonical role | 本 repo 的 Linear label | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 維護者需要評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交給 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工實作 |
| `wontfix` | `wontfix` | 不會處理 |

Skill 提到 role 時，使用表格右欄對應的 Linear label 字串。
