## What it does

writing-router-skill is a router: one page that names every skill in this repo and states when to reach for each, so you don't have to hold the whole `skills/` tree in your head to pick the right tool. It only routes — it never does the work of the skill it points you to.

## When to reach for it

You invoke this by typing `/writing-router-skill` — the agent won't reach for it on its own. Reach for it when you're not sure which skill in this repo fits what you're about to do, or you just want the map before picking a tool.

## Where it fits

A reach-for-it-anytime standalone skill — the map itself, not a step in anyone else's flow. Every other promoted skill's docs page points back here.
